How it works

  1. Your code is fetched from SoloLearn, into your browser. (No backend!)
  2. The HTML, CSS and JS are joined into a single page.
  3. That page runs inside a sandboxed iframe each time someone opens your link.
  4. Links are permanent. The URL never changes, and edits you make on SoloLearn show up automatically, as long as the code stays public.
